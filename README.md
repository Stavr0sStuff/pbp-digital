# Please Be Patient Digital

Digital playtest version of Please Be Patient, a quirky little card and dice manipulation game where you try to treat all your patients while keeping your equipment working and avoid the waiting room for overcrowding.

This game participates in the BGG Solo Design Contest 2026. You can find the thread [here](https://boardgamegeek.com/thread/3753626/wip-please-be-patient-1p-card-placement-dice-manip)

**Play the app:** https://stavr0sstuff.github.io/pbp-digital/
